# 🇷🇸 Srpski

Web aplikacija za upravljanje skladištem — PHP OOP, MySQL, Bootstrap 5.

## Funkcionalnosti
- 🔐 Prijava i registracija sa ulogama (admin / korisnik)
- 📦 CRUD upravljanje artiklima
- 🔄 Ulaz / izlaz robe sa historijom transakcija
- 📊 Dashboard sa statistikama i upozorenjima
- 🏷️ Upravljanje kategorijama i dobavljačima
- 🛡️ Admin panel za upravljanje korisnicima
- 🔍 Pretraga i filtriranje

## Instalacija

```bash
# 1. Kloniraj repozitorijum
git clone https://github.com/TVOJE_IME/skladiste-app.git

# 2. Premjesti u C:\xampp\htdocs\skladiste\

# 3. Importuj bazu u phpMyAdmin
#    Baza: skladiste_db | Fajl: config/schema.sql

# 4. Konfiguriši bazu
cp config/database.example.php config/database.php

# 5. Otvori http://localhost/skladiste/
```

# 🇬🇧 English

# 📦 SkladišteApp

Warehouse management web application — PHP OOP, MySQL, Bootstrap 5.

## Features
- 🔐 Login & registration with roles (admin / user)
- 📦 Full CRUD item management
- 🔄 Stock in / out with transaction history
- 📊 Dashboard with statistics and alerts
- 🏷️ Category and supplier management
- 🛡️ Admin panel for user management
- 🔍 Search and filtering

## Installation

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/skladiste-app.git

# 2. Move to C:\xampp\htdocs\skladiste\

# 3. Import database in phpMyAdmin
#    Database: skladiste_db | File: config/schema.sql

# 4. Configure database
cp config/database.example.php config/database.php

# 5. Open http://localhost/skladiste/
```
